# 现场部署准备目录

本目录可在填写完成后复制到 Orin 的 `~/stair_site/`，也可保留在仓库内并在启动时传入这里的绝对路径。部署与编译步骤见[主 README](../README.md)。

**当前是待填写的现场配置。路线、地图和路径含空值，不能直接启动巡检。** `m20_orin.yaml` 为原厂接口模板副本，保留只读、未确认和仅平地的默认设置。

| 文件 | 当前内容 | 后续需要填写 |
|---|---|---|
| `route.yaml` | 路线结构占位 | 坐标系、实测节点、路段、跟踪/规划/到达参数 |
| `mission.yaml` | 任务 ID、相对路线路径、空执行序列 | 与路线一致的段序列及需要调整的任务参数 |
| `m20_orin.yaml` | 项目自带 M20 接口模板 | 实际接口、已验证能力、模式和速度限制 |
| `maps/floor_1.yaml` | 平台地图字段占位 | 转换后的占据栅格及真实几何参数 |
| `maps/stair_ab.yaml` | 楼梯地图字段占位 | 使用高度栅格规划时的占据与支撑高度 |
| `paths/ab.yaml` | 空预设路径 | 使用独立预设路径文件时的实测路径点 |

按实际后端选择地图或预设路径，不必同时使用全部占位文件。路线的相对地图/路径引用从本目录解析，任务的 `route_file: route.yaml` 也指向本目录。

建议先填写平地 A→B 的最小路线并完成实机闭环，再增加多段和楼梯。不得将空地图填成全空闲、复制演示坐标或虚报能力来通过预检。

本目录不包含原厂定位地图、固件匹配的 `drdds` 消息包、支撑参考估计程序及楼梯保持/出梯监督程序。这些仍需按主 README 接入；创建 YAML 占位不会提供对应运行输入。

M20 模板的 `normal_location_status=-1` 表示未确认，`dry_run=true` 表示只读。完成现场核实后，需按主 README 显式传入定位正常码及实机启动参数；这些 launch 参数会覆盖 YAML 中的同名值。
